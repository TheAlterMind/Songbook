Lyrics Library — Bulk Add Tool

Fill in a song, add it to the batch, repeat as many times as you like, then download one file to import into the app.

1. Fill in the form and click Add to batch for each song.
2. When you're done, click Download JSON.
3. Get that file onto your phone — USB cable, a cloud drive, or emailing it to yourself all work.
4. In the app: Settings → Import from file, then pick it. Songs already in your library (matched by title + artist) are skipped automatically.
